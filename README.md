# RAG-ассистент для изучения Python

Telegram-бот с RAG-системой для изучения Python по учебнику **«Изучаем Python» Эрика Мэтиза**.

Бот отвечает на вопросы по учебнику, даёт практические задачи с проверкой кода, проводит викторины и сохраняет прогресс.

## Возможности

- Вопросы по учебнику (RAG)
- 10 разделов с отметками о просмотре
- Практические задачи с проверкой через LLM
- Безопасное выполнение кода
- Викторина «Испытать удачу» (10 вопросов из 100) + топ
- История диалога и прогресс в SQLite
- Админ-команды (рассылка, список пользователей)

## Требования

- Python 3.10+
- Аккаунт Telegram
- Ключ Groq API (бесплатный)

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/alh1m1knhrn/rag-system.git
cd rag-system
```

### 2. Создать виртуальное окружение

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Получить токен бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Придумай имя и username бота
4. Скопируй полученный токен

### 5. Получить ключ Groq

1. Зарегистрируйся на [console.groq.com](https://console.groq.com)
2. Создай API-ключ
3. Скопируй его

### 6. Создать файл `.env`

В корне проекта создай файл `.env` со следующим содержимым:

```env
GROQ_API_KEY=твой_ключ_groq
GROQ_MODEL=openai/gpt-oss-120b
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=твой_telegram_user_id
```

**Как узнать свой user_id:**  
Напиши боту [@userinfobot](https://t.me/userinfobot) — он пришлёт твой ID.

> Файл `.env` не попадает в Git (он в `.gitignore`).

### 7. Подготовить учебник

Положи файл учебника в папку `data/`:

```
data/textbook.docx
```

Если файла нет — бот всё равно запустится, но кнопка «Скачать учебник» будет выдавать предупреждение.

### 8. Запустить бота

```bash
python src/interfaces/telegram_bot.py
```

При первом запуске автоматически создадутся:
- `data/chroma_db/` — векторная база
- `data/rag_bot.db` — база с историей, прогрессом и пользователями

В консоли должно появиться:
```
База данных инициализирована: ...
Бот запущен.
```

### 9. Проверить работу

1. Найди своего бота в Telegram
2. Нажми `/start`
3. Попробуй задать вопрос или открыть разделы

## Команды бота

### Для пользователей

| Кнопка | Описание |
|--------|----------|
| ❓ Задать вопрос | Вопрос по учебнику |
| 💻 Выполнить код | Запуск кода |
| 📚 Разделы | Главы с прогрессом |
| 📝 Задачи | Практические задания |
| 🍀 Испытать удачу | Викторина |
| 🏆 Топ викторины | Таблица лидеров |

| Команда | Описание |
|---------|----------|
| `/users` | Список пользователей |

| `/broadcast <текст>` | Рассылка всем |

## Возможные проблемы

**Бот не запускается, ошибка про GROQ_API_KEY или BOT_TOKEN**  
→ Проверь, что файл `.env` лежит в корне проекта и ключи указаны правильно.

**Не отвечает на вопросы по учебнику**  
→ Убедись, что в `data/` есть файл учебника и папка `chroma_db` создалась.

**Команды /users, /broadcast не работают**  
→ Проверь, что в `.env` указан правильный `ADMIN_ID`.
