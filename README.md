# RAG-ассистент для изучения Python

Telegram-бот с RAG-системой для изучения Python по учебнику **«Изучаем Python» Эрика Мэтиза** (3-е издание).

Бот отвечает на вопросы по учебнику, даёт практические задачи с проверкой кода, проводит викторины и отслеживает прогресс пользователя.

## Возможности

- **Вопросы по учебнику** — ответы на основе RAG (поиск по тексту книги + генерация)
- **8 разделов** — главы 1–8 с отметками о просмотре
- **Практические задачи** — решение кодом с проверкой через LLM (плюсы/минусы + эталон)
- **Безопасное выполнение кода** — запуск кода пользователя в песочнице
- **Викторина «Испытать удачу»** — 10 случайных вопросов из базы в 100, с топом
- **Прогресс и история** — сохраняются в SQLite между перезапусками
- **Очистка** — отдельно контекст диалога и прогресс

## Стек

- **RAG**: LangChain + ChromaDB + HuggingFace embeddings (`paraphrase-multilingual-MiniLM-L12-v2`)
- **LLM**: Groq API (`openai/gpt-oss-120b`)
- **Бот**: Aiogram 3
- **База данных**: SQLite + SQLAlchemy
- **Выполнение кода**: AST-проверка + subprocess

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/alh1m1knhrn/rag-system.git
cd rag-system
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить переменные окружения

Создай файл `.env` в корне проекта:

```env
GROQ_API_KEY=твой_ключ_groq
GROQ_MODEL=openai/gpt-oss-120b
BOT_TOKEN=токен_твоего_бота
```

Ключ Groq можно получить на [console.groq.com](https://console.groq.com).  
Токен бота — у [@BotFather](https://t.me/BotFather) в Telegram.

### 5. Подготовить данные

Положи файл учебника в папку `data/`:

```
data/textbook.docx
```

При первом запуске бот создаст:
- `data/chroma_db/` — векторная база
- `data/rag_bot.db` — SQLite с историей и прогрессом

## Запуск

```bash
python -m src.interfaces.telegram_bot
```

Или из корня:

```bash
python src/interfaces/telegram_bot.py
```

## Структура проекта

```
rag-system/
├── data/                  # Учебник, ChromaDB, SQLite
├── src/
│   ├── code_executor/     # Безопасное выполнение кода
│   ├── db/                # Модели и CRUD (SQLite)
│   ├── ingestion/         # Парсинг и индексация учебника
│   ├── interfaces/        # Telegram-бот
│   ├── quiz/              # База вопросов викторины
│   ├── rag/               # RAG-цепочка и промпты
│   └── config.py          # Настройки и ключи
├── tasks.py               # Практические задачи
├── requirements.txt
└── README.md
```
